HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in a browser.

HOW TO PUBLISH FOR FREE WITH GITHUB PAGES
1. Sign in to GitHub and create a new PUBLIC repository (for example: elvo-store).
2. Upload index.html and the entire assets folder (keep the folder structure).
3. Open the repository's Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. GitHub will provide your live website address after deployment.

EDITING PRODUCTS
Open index.html in a text editor and find the products array near the bottom.
Change names, prices, image filenames, and available:true/false as needed.
For a sold-out item, use available:false.
